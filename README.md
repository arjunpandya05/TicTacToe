## Description of the game.

Two-player Tic-Tac-Toe game uses Node.js, Express, HTML, CSS, JavaScript, and WebSockets. Two players can join a shared game under the same link, and additional visitors can spectate again using the same link.

## To run locally

1. Run `npm install` in this directory.
2. Run `npm start`.
3. Open `http://localhost:3000`.


## To run in general

Open the live URL in two browser windows, and then enter a name and the secret password to join as players. The third browser window can spectate, additional will also be spectators.
